プライバシーポリシー（Reskilling Video Sync）

ワイズ株式会社　最終更新日: 2026年9月14日

本ポリシーは、ワイズ株式会社（以下「当社」）が運用するアプリケーション「Reskilling Video Sync」（以下「本アプリ」）における情報の取り扱いについて定めるものです。

1. 本アプリの目的

本アプリは、当社が運営する YouTube チャンネル（ファーマシストキャンパス等）の動画情報・分析データを取得し、当社の告知業務および運営分析に利用するための社内向けツールです。一般の利用者向けに提供するものではありません。

2. 取得する情報

本アプリは Google API（YouTube Data API・YouTube Analytics API）を通じて、当社が管理する YouTube チャンネルに関する以下の情報を取得します。

  • チャンネルおよび動画のメタデータ（タイトル、説明、公開日時、公開設定など）
  • チャンネルの分析データ（視聴数などの統計情報）
  • 動画のアップロードおよび公開設定の変更に必要な情報

本アプリは、当社が管理するチャンネル以外の個人情報を取得しません。

3. 利用目的

  • 当社チャンネルの新着動画の社内告知および SNS 告知の作成
  • 当社チャンネルの運営状況の分析

4. 保存と管理

取得した情報は当社が管理する機器内に保存し、業務上必要な範囲でのみ利用します。認証情報（トークン）は当社の管理下で厳重に保管し、第三者に開示しません。

5. 第三者への提供

当社は、法令に基づく場合を除き、取得した情報を第三者に提供・販売しません。

6. Google API サービスのユーザーデータに関するポリシーへの準拠

本アプリによる Google API から取得した情報の利用は、Google API Services User Data Policy（Limited Use の要件を含む）に準拠します。

7. アクセス権の取り消し

本アプリに付与した Google アカウントのアクセス権は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消すことができます。
